# ONG Esperança para Todos

Projeto acadêmico de desenvolvimento front-end desenvolvido como parte da graduação em Engenharia de Software.

O projeto consiste na criação de um site institucional para a **ONG Esperança para Todos**, uma organização fictícia voltada à promoção de ações sociais, inclusão e voluntariado.

## Sobre o projeto

O site apresenta informações sobre a organização, seus projetos sociais e formas de participação.

O projeto foi desenvolvido utilizando recursos fundamentais do HTML5, com foco em:

* Estrutura semântica;
* Organização de conteúdo;
* Navegação entre páginas;
* Formulários HTML5;
* Validação de dados;
* Acessibilidade básica;
* Uso adequado de elementos HTML;
* Organização de arquivos e diretórios.

## Tecnologias utilizadas

* HTML5
* Git
* GitHub
* W3C Validator

## Páginas

### Início

A página inicial apresenta a ONG, sua missão e informações de contato.

### Projetos

Apresenta os principais projetos e formas de contribuição, incluindo voluntariado e doações.

### Cadastro

Contém um formulário HTML5 para cadastro de pessoas interessadas em participar dos projetos da ONG.

O formulário utiliza recursos como:

* Campo de nome;
* CPF com validação de formato;
* Data de nascimento;
* E-mail;
* Telefone com validação de formato;
* CEP com validação de formato;
* Endereço;
* Cidade e estado;
* Opções de participação;
* Campo de mensagem;
* Termos de participação.

## Validação

Os arquivos HTML foram desenvolvidos seguindo a estrutura do HTML5 e podem ser verificados por meio do **W3C Validator**.

## Objetivo acadêmico

Este projeto tem como objetivo aplicar na prática conhecimentos de desenvolvimento front-end, especialmente conceitos relacionados à estruturação de páginas HTML5, semântica, formulários, acessibilidade e organização de um projeto web.
